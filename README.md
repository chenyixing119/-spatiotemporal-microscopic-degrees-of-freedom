This repository hosts the full PDF documents for the conceptual framework note: *Spatiotemporal Microscopic Degrees of Freedom*.

## Available Versions

- **English Version**: `Spacetime_Microscopic_Degrees_of_Freedom.pdf`
- **Chinese Version**: `时空微观自由度_从时空微观自由度看物理基础.pdf`

## About This Work

> **Note**: This is a conceptual framework note, not a standard physics theory paper.
> - It presents no new mathematical equations or experimental predictions.
> - It does not challenge any experimentally verified results of General Relativity or Quantum Mechanics.
> - Instead, it proposes a "delocalized-condensed" continuum to reinterpret gravity and rest mass.
